美剧字幕→英语预习笔记

给 AI 一个剧名和季集，它自动获取字幕、筛选生词、编写释义，生成一份可直接打印的 A4 预习笔记。看剧前先过一遍，跟上台词不费力。

三步生成预习笔记

给剧名 → AI 选词 → 得笔记，全程无需手动整理

1

提供字幕

直接上传 .srt / .ass / .vtt / .txt 字幕文件，或告诉 AI 剧名与季集号，由它去检索

2

AI 智能选词

按超纲实词、短语搭配、俚语口语、派生词四级优先级筛选，结合语境编写释义

3

输出笔记

生成自包含 A4 HTML（可直接打印/导出 PDF）+ Markdown 摘要，附回看时间点

安装

三种方式，一行命令即可完成安装。安装后新开一个会话，对 AI 说"字幕笔记""预习笔记"即可触发。

curl macOS / Linux ▼
curl -fsSL https://raw.githubusercontent.com/Liliane0310/english-subtitle-learning/main/install.sh | bash
PowerShell Windows ▼
irm https://raw.githubusercontent.com/Liliane0310/english-subtitle-learning/main/install.ps1 | iex
npx 任意平台（需 Node） ▼
npx github:Liliane0310/english-subtitle-learning

手动安装

git clone 后执行 install.sh（Windows 用 install.ps1）

触发词

安装后，对 AI 说以下任意一种即可触发

"字幕笔记"
"预习笔记"
"看剧前先学词"
"把这集字幕整理成笔记"
